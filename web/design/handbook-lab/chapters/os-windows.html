Windows

Terminal emulators

Windows Terminal hosts command-line applications, including Command Prompt, PowerShell and WSL shells. It supplies tabs, panes and rendering; it is not itself the command language.[40]

Shell

PowerShell is a shell and automation language built around commands and objects. PowerShell 7.x is cross-platform; it is distinct from the Windows PowerShell 5.1 component. Bash commands elsewhere in these notes are Linux examples, not PowerShell syntax.[41][139]

Corporate licensing

Use the product edition, acquisition channel and governing agreement to determine licensing rights. Installation or activation alone is not an inventory of an organization’s entitlements. Keep license records and route compliance questions, reports or vendor audit requests through the organization’s licensing/legal team.[42]

Reporting channels, third-party auditors and enforcement practices vary by vendor, agreement and jurisdiction; no particular auditor or reporting organization is universally involved. This is an administration reminder, not legal advice or a statement about any employer’s compliance.
