Commands

Examples use Bash and GNU/Linux tools on RHEL 9. Command names, options and most file names are case-sensitive. In synopsis notation, brackets mean optional arguments, not literal characters to type; replace names such as DIR, FILE, DEVICE and USER with the verified target.[18][19]

command [-f] [--flag] arguments

Inspect with unprivileged commands first. Administrative commands below require the appropriate authorization; do not add sudo to a command merely to hide a permission error.

Help, discovery and system information

The command table distinguishes discovery from actions that change mounts, databases, host identity or time.[20][19][54]

Command Meaning
command -v CMD Bash-aware command lookup; may report a builtin, function, alias or path
which CMD External PATH lookup where installed; does not reliably describe every shell construct.[125]
find DIR -name '*.conf' Search below DIR by basename; quote patterns so the shell does not expand them first
find DIR -wholename '*/config/*' GNU find full-path match; -path is the more portable spelling
locate PATTERN Search a prebuilt filename database if a locate implementation is installed; results may be stale or exclude paths.[131]
updatedb Rebuild that locate database with the implementation’s configuration, often /etc/updatedb.conf; an authorized maintenance action that can traverse many files
whatis CMD Short manual-page description from the manual index.[127]
man CMD Manual page; specify a section such as man 5 passwd when needed.[112]
CMD --help Built-in help for commands supporting this convention
df -h FILE Filesystem space usage for the filesystem containing FILE; omit FILE to list filesystems
du -h -d 1 DIR Storage usage for DIR and one level of subdirectories; allocated blocks need not equal apparent file size
lsblk / lsblk -f Block-device topology / filesystem information.[100]
findmnt Current mount information.[101]
mount DEVICE MOUNTPOINT Mount a verified filesystem; requires appropriate privileges/policy
umount MOUNTPOINT Unmount; it may fail while files or working directories are in use
Ctrl+r / history Search / list Bash command history; never place passwords in commands to begin with
w Logged-in sessions and activity, including TTY, login/idle and CPU information.[110]
who Logged-in sessions and terminals
last Login history where records exist; not proof that every access path was audited.[111]
whoami Effective user name; not necessarily the original login identity
who am i Login record for the current terminal, if one exists
users Names associated with current login records
finger Optional user-information utility; frequently absent or restricted; not required for administration
stat FILE Metadata including access, modification and status-change times. ctime is not creation time
date Print date/time. Setting time is a separate privileged action and can disrupt logs/authentication
hostnamectl status Systemd host/OS/kernel information; /etc/os-release describes the OS
hostnamectl set-hostname NAME Set hostname when authorized; coordinate DNS, monitoring and application identities first
uname -a Kernel/system information; not the full distribution/package inventory

Before mounting, verify the source device and destination with lsblk -f and findmnt; mounting over a nonempty directory hides its existing contents until unmount.[102] Do not unmount a filesystem with active database/application work or force-detach it as a routine fix.[103] For new filesystems and destructive operations, use the partition procedure.

File management and text processing

Use these operations inside a known working directory. cp, mv, redirection and archive extraction can overwrite existing data. rm has no general undo: inspect expanded names and protect backups before removal. Do not experiment on system, database or shared directories.[19][21]

Command Meaning
cd PATH / cd - Change directory / return to the previous directory
ls List directory entries
ls -l Long format. ll works only if your environment defines that alias/function
ls -a Include dot entries and hidden names
ls -lh Human-readable sizes with long format
ls -lu Display access time instead of modification time in long format; -u also interacts with sorting
lsof List open files; visibility depends on privileges and process namespace.[113]
cp SOURCE DEST Copy; existing destination data can be overwritten
cp -r DIR DEST Recursive copy; choose -a when the intended semantics are metadata-preserving archive copy
mv SOURCE DEST Move/rename; can replace a destination
mkdir DIR / mkdir -p parent/child Create a directory / create required parents
rm FILE Remove a file name; irreversible without another copy
rm -r DIR Recursively remove a directory tree; verify every selected path first
rm -f FILE Suppress prompts and ignore nonexistent operands; does not make removal safer
rmdir DIR Remove an empty directory
touch FILE Update timestamps; create an empty file if it does not exist
echo 'text' Write text to standard output; use printf when portable escape/option behavior matters
cat FILE1 FILE2 Concatenate content to standard output
CMD > FILE / CMD 1> FILE Redirect stdout, truncating FILE
CMD 2> FILE Redirect stderr, truncating FILE
CMD &> FILE Bash: redirect stdout and stderr to one file
CMD >> FILE Append stdout; use 2>> for stderr or Bash &>> for both
grep -v 'word' FILE Exclude lines matching the expression
grep -w 'word' FILE Match the expression as a whole word
awk '{print $1, $2}' FILE Print the first two whitespace-separated fields
cut -c1 FILE Select the first character position of each line
sed -n '5p' FILE Print only line 5
CMD | less Page through command stdout; there is no stout command
head FILE / tail FILE Show the beginning/end of a file
tar -cvf archive.tar FILES Create an uncompressed tar archive
tar -Avf a1.tar a2.tar Concatenate the members of uncompressed a2.tar onto a1.tar; does not merge compressed archives
tar -rvf a1.tar FILES Append files to an uncompressed archive
tar -czvf archive.tar.gz DIR Create a gzip-compressed tar archive
tar -tf archive.tar.gz List archive members; GNU tar recognizes compression when reading a file
tar -xvf archive.tar.gz Extract into the current directory; use only after listing and selecting a safe destination
gzip FILE Compress, normally replacing the input with FILE.gz; gzip -k FILE retains it

For the filter examples, grep matches text, sed selects a line here, and Awk selects fields; these are distinct languages with their own quoting rules.[73][74][75]

gzip normally replaces its input; use its keep option when retaining the original is required.[76]

Expansion happens before the command runs. The source-style expression file00{4,5,6} expands to three names; f3* can match many more than intended. Inspect instead of deleting while learning:

printf '%s\n' file1 file2 f3* file00{4,5,6}

For an archive, first list its contents, then extract as an unprivileged user into a new, empty, dedicated directory, not over a live tree. Treat untrusted archives as untrusted files even when tar rejects common traversal paths. Appending to a tar file or creating an archive with an existing output name changes that file; preserve the prior archive if it is a backup.[21][18]

Vim windows and editing

The split orientation names refer to the separating boundary: horizontal splits are stacked, vertical splits are side by side.[22]

The editing and formatting commands below follow Vim’s editing and option manuals.[77][78]

Command Meaning
vim -o file1 file2 Open stacked horizontal splits
vim -O file1 file2 Open side-by-side vertical splits
:r FILE Insert a file’s content below the current line
:set textwidth=80 Set an automatic formatting width; behavior depends on formatting options and insertion/reformatting, not display-only wrapping of all existing lines
:split FILE / :vsplit FILE Horizontal / vertical split
:qa Quit all windows; refuses when unsaved changes require attention
:only Close other windows, subject to modified-buffer checks
:wq / ZZ Write and quit; ZZ writes only if the buffer changed
Ctrl+w then an arrow Move to the adjacent window

Ownership, permissions and attributes

Change permissions only on files you are authorized to administer. Broad recursive ownership/permission changes can expose secrets or break services; inspect the exact path and current settings first.[19]

Command or notation Meaning
chown USER:GROUP PATH Change owner and group (requires suitable privilege); chown USER PATH changes the owner
chgrp GROUP PATH Change group ownership subject to permissions
chmod u=rw,g=r,o= FILE Explicit symbolic mode example; u, g, o mean owner, group and other; +, -, = add/remove/set selected bits
chmod 640 FILE Numeric mode: read = 4, write = 2, execute/search = 1 for each owner/group/other digit
chmod +t DIR / chmod -t DIR Set/remove sticky bit. In a writable directory it restricts removal/rename to authorized owners or privileged processes; it does not prevent modification of writable file contents
t versus T in ls -l Sticky bit with / without the other-execute bit
chattr +a FILE Append-only attribute on supporting filesystems; writes must append. Setting/clearing protected attributes requires appropriate privilege
chattr +i FILE Immutable attribute on supporting filesystems; a suitably privileged administrator can clear it, so it is not protection from all root actions
lsattr FILE Inspect supported file attributes
umask Display the current creation mask
umask 022 Mask group/other write on future creations in this shell and descendants, subject to the requested mode and default ACLs

Without a default ACL, creation permissions are requested mode AND the complement of umask. For the usual requested modes, mask 022 gives files 0644 from 0666 and directories 0755 from 0777; mask 002 gives files 0664. This is bit clearing, not a universally valid subtraction formula, and does not alter existing files. Default ACL inheritance can change the calculation.[88][19]

Append-only and immutable attributes are filesystem-specific controls, separate from mode bits.[53]
