Vocabulary and editions

MySQL is an RDBMS. In MySQL, database and schema are synonyms for a namespace of tables and other objects. A table definition describes columns, types, indexes and constraints; a schema can also contain views, routines, triggers and events. Foreign keys express relationships where the storage engine supports them.

Community and Enterprise are distributions/licensing offerings, not simply the same server with a fixed extra-utility list. Check the purchased edition and component package before planning a feature.

Original category Availability and purpose in the 8.4 family
mysqlbackup MySQL Enterprise Backup, separately versioned commercial physical-backup product.
mysqlmonitoragent, Enterprise Monitor Commercial monitoring product/agent, not a core mysqld executable; deployment and lifecycle are separate.
MySQL Router Available with Community as well as commercial offerings; routes client connections and is not an Enterprise-only backup tool.
Audit, Firewall, Thread Pool Enterprise features; they are not automatically installed or enabled merely because the server starts.
PAM and LDAP authentication Enterprise authentication integrations; depend on platform, plugin and identity-service configuration.
Keyring A framework with different implementations: component_keyring_file is available in Community; encrypted-file and external key-management choices have edition-specific availability. Loading a keyring does not encrypt tables.
Connectors Separately versioned drivers with their own compatibility/support and licensing terms; “Advanced Connectors” is not a universal server feature switch.

Choose a supported 8.4 LTS maintenance release rather than assuming the first 8.4.0 build is the deployment target. The official release policy gives LTS a stable feature set and five years of Premier plus three years of Extended Support; entitlement terms and platform support still apply.
